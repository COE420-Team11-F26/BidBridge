# BidBridge — Critical Path

**Critical Path:** T1 → T2 → T3 → T4 → T5 → T7 → T8

**Expected Project Duration:** 61 days

**Explanation:** The critical path was found by calculating ES, EF, LS, LF and Slack for every task (see `Network_Schedule/Network_Schedule.md`). The tasks T1 → T2 → T3 → T4 → T5 → T7 → T8 all have zero slack, so any delay in one of them delays the whole project. T6 (Admin and Disputes) and T9 (Documentation) each have 1 day of slack and can be delayed by one day without changing the completion date.
