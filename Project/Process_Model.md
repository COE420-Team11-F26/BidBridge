
1. The model selected for BidBridge is the Incremental model. 

2. The Incremental model is appropriate for this project as BidBridge is going to have numerous features like job posting, bidding and payment release, and each feature can be considered as its own iteration. Additionally the incremental model allows us to have a parallel process, meaning we can work on some of these features simultaneously. Each feature would be broken down into its own subproject where at the end of each one we can gain user feedback and then either iterate to a new feature or go back and improve the current one.

3. The Major drawbacks associated with the Incremental model is the need for extensive and detailed upfront planning. Additionally, another drawback is going to be the complicated integration and putting the subparts back together, that may lead to increased cost/time. We will manage these drawbacks by establishing the detailed system requirements early, and regularly testing the integration of each of the iterations together.
