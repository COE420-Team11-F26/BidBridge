1.	Technical Feasibility
BidBridge is technically feasible as it can be developed without any hardware and mainly using web development for the frontend, and the backend would consist of actions for the functional requirements and databases to store and query information. The team has all taken and learned the necessary programming and software skills needed to implement the main features. The main technical obstacle that would be overcome is securely handling payments, other from that all other aspects are straightforward, leading to the full project being technically feasible. 


2.	Economic Feasibility
BidBridge is economically feasible, as the development can be completed using mostly free development tools, and low cost services that might be used to host the database and the payment gateway. Overall it is very economically feasible and wouldn’t constrain the budget in any way. 


3.	Operational Feasibility
BidBridge addresses a genuine need, by connecting clients who need work completed with freelances who are looking for jobs and task opportunities. The bidding system allows the clients to receive the lowest fares for their tasks, while simultaneously providing payment reliability to the freelances ensuring they get paid. Therefor the users are very likely and highly incentivised to use and accept the system.  


4.	Schedule Feasibility
Bidbridge has schedule feasibility as well, since the development would be broken down into iterations and the team of four can each focus on a main feature and its integration. This can reasonably be done within the available course duration.


5.	Overall Feasibility
Overall, the project is completely feasible from a technical, economic, operational and scheduling perspective. It checks off each feasibility factor, with the main constraint being the secure payment integration and the overall integration of all components within the system.
