## 1. Project Objective

The objective of BidBridge is to provide a structured freelance job platform that connects clients who need work completed with freelancers who are looking for job opportunities. The platform aims to improve trust and fairness by allowing freelancers to compete through bidding while protecting both sides through an escrow-style payment process, where payment is held until the client approves the completed work.

## 2. Target Users

The main target users of BidBridge are:

- **Clients:** Users who want to post jobs, review freelancer bids, select a freelancer, and approve completed work.
- **Freelancers:** Users who want to browse available jobs, submit competitive bids, complete assigned work, and receive payment after approval.
- **Platform administrators:** Users responsible for managing accounts, moderating listings, monitoring transactions, and handling disputes or flagged activity.

## 3. In-Scope Features

The initial version of BidBridge will include the following major features and functionalities:

- User registration and login.
- Separate client and freelancer user roles.
- User profile management.
- Clients can create and manage job postings.
- Job postings can include a title, description, required skills, budget, and deadline.
- Freelancers can browse available jobs.
- Freelancers can submit bids that include a proposed price and relevant details.
- Clients can review and compare submitted bids.
- Clients can select a freelancer for a posted job.
- Basic job status tracking, such as open, assigned, submitted, and completed.
- Freelancers can submit completed work for client review.
- A simulated or integrated escrow-style payment process where payment is held until the client approves the work.
- Payment release after client approval.
- Basic user ratings or reputation information after completed jobs.
- Administrative tools for managing users, job postings, and reported activity.

## 4. Out-of-Scope Features

The following features will not be included in the initial version of BidBridge:

- Full integration with international banking systems.
- Cryptocurrency payments.
- Advanced fraud detection using machine learning.
- Automatic legal contract generation.
- Real-time video calls or built-in video conferencing.
- A dedicated mobile application.
- International tax calculation and tax filing support.
- Advanced AI-based freelancer or job recommendation systems.
- Support for multiple external payment providers at the same time.
- Complex dispute arbitration involving external legal services.

These features may be considered in future versions of the system.

## 5. Major Deliverables

The major expected deliverables of the BidBridge project are:

- A functional BidBridge web-based prototype.
- User registration, login, and profile management functionality.
- Client job posting and job management functionality.
- Freelancer job browsing and bidding functionality.
- Bid review and freelancer selection functionality.
- Work submission and approval functionality.
- Escrow-style payment holding and release functionality.
- Basic administrator management features.
- Project planning and software engineering documentation.
- Source code maintained in the team GitHub repository.
- Testing and evaluation documentation.
- Final project documentation and presentation.
